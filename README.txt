POLARIZED THOMSON TRANSPORT IN A SLAB — PAPER COMPANION
Release candidate updated 2026-10-26

1. Purpose and quick start
==========================
We provide calculations, paper figures and supporting checks for our slab
Stokes-recursion framework. The companion includes numerical MCRT and compPSc
benchmarks and derived 4U 1624-49 spectral-fit exports. Ordinary execution does
not rerun those simulations or observational fits.

For the independent observational processing record, open
observational_analysis.ipynb. Its Run All is offline: it displays event-region
images, time cuts, ungrouped extraction channels, best-fit parameters and native
joint-fit spectra/residuals with the three IXPE DUs kept separate. It never
executes XSPEC, extraction, optimization or chains. See data/observations/README.txt
for the provenance and limitations of the lightweight observational exports.
Section 9 distinguishes fit grouping from display rebinning, compares IXPE I
before/after grouping, and explicitly recomputes Q/U overlap-weighted bins,
three-DU sums and their covariance. Merged plots do not replace the joint fit.

Keep this complete folder together; the notebook alone is not sufficient.
From this folder, in a dedicated Python environment, run:

    python -m pip install -r requirements.txt
    jupyter lab paper_companion.ipynb

Select the corresponding kernel and run all cells from top to bottom.
requirements.txt gives dependency lower bounds, not a locked environment.
execution_report.json records the versions checked for the bundled run.
A private compPSc installation, XSPEC, remote servers and network access are
not needed after installing dependencies.

4. Data inventory and conventions
=================================
data/transport/          Recursion/eigenmode caches (NPZ).
data/thermal_angular/    Cached 20 keV thermal-angular diagnostic and grid audits.
data/avoided_crossings/  Full-matrix eigenpairs, gaps, overlaps and grid checks.
data/order_validation/  Cold-electron order-resolved MCRT counts and statistics.
data/mean_validation/   Independent mean-scattering validation cases.
data/spectra/           Five-case MCRT/Jones/compPSc spectral comparisons.
data/bestfit_validation/ Low-/high-reflection MCRT/Jones spectra and run audits.
data/western/           Derived spectral-fit and model-component exports.
data/observations/      Region images, ungrouped channels, GTIs and command records.
data/statistics/        81-case summaries and selected-bin comparison table.

We use total slab Thomson optical depth. In our comparison convention,
surface Q is positive parallel to the slab surface. Where a raw MCRT export
uses the opposite sign, the loader converts it once; do not reverse it again.
Consult individual sections and data/statistics/PER_BIN_DATA.txt for units and
normalization. Observational flux exports and per-injected-photon simulation
spectra do not share the same absolute units.

Order-resolved checks cover three seed configurations. Some histories reach
the 32-scattering cap; the displayed escaped orders n <= 10 remain available,
but these runs do not certify the full scattering tail or mean. The separate
mean-scattering checks span 14 depths for each of three seed sources. One
uniform-source history at tau = 12.2633 reaches its cap (1/30000). We retain
capped histories without a tail correction. Marginal errors across orders
are not independent; sampling errors omit possible censoring bias.

Best-fit coronal checks use diskbb seeds with Tin = 0.6 keV and Lambert
injection. Each branch has 128 independent batches of one million histories.
We bundle derived statistics and run metadata, not raw photon trajectories
or all individual batch spectra. Both surfaces and Pi(E) are displayed.

5. The 81-case selected-bin comparison table
==========================================
data/statistics/point_contributions.csv.gz is approximately 6.5 MiB compressed
(29.9 MiB uncompressed), with 146248 rows. It covers 81 parameter pairs, two
models, both surfaces, two angle windows and I/Q. We retain model predictions,
MCRT means and standard errors, energy edges and chi-square contributions.
compPSc numerical outputs are included; its private source code is not.

We use 5 eV blackbody seeds, Lambert injection, 0.3 <= tau <= 20 and
1 <= kTe <= 40 keV. Each MCRT case has 400 million histories in 400 batches.
Only reference-selected bins used in the heatmaps are included: bin centers
between 0.005 keV and 5 kTe, count >= 50, at least 8 occupied batches,
reference E^2 I above 1e-8 of its band peak, and finite positive SE. There is
no Q-significance cut. This table cannot recover excluded bins or their counts;
arbitrary new support cuts require the original full spectra.

From this folder:

    import pandas as pd
    p = pd.read_csv('data/statistics/point_contributions.csv.gz')
    keys = ['model', 'case', 'boundary', 'window', 'stokes']
    stats = p.groupby(keys).chi2_contribution.agg(['sum', 'count', 'mean'])

sum, count and mean reproduce chi2, N and chi2/N. No physical parameter or
amplitude is fitted to the MCRT points. Repeated MCRT values in the two model
groups are the same reference, not independent simulations. PER_BIN_DATA.txt
documents the schema; per_bin_validation.json records the checks. Exploratory
peak-uncertainty-scaled maps do not replace the adopted unscaled chi2/N maps.

6. Execution, caches and verification
=====================================
The default ALLOW_EXPENSIVE_RECOMPUTE = False uses bundled numerical caches.
Missing caches cause an error, not a simulation launch. Modest recursions and
coefficient fits still run locally. The first code cell checks the data hashes.

Enable ALLOW_EXPENSIVE_RECOMPUTE only to intentionally recompute eigenproblems.
Section 12.4 also requires RECOMPUTE_AVOIDED_CROSSINGS = True to rerun the gap
scan. These controls do not regenerate MCRT, compPSc or observational fits.
Changed parameters and regenerated caches require their own validation; do
not silently bypass a checksum mismatch. Paper figures are written to figure/;
supporting figures, including the k^6 and gap diagnostics, are displayed only.

The original full notebook run passed 37 code cells and produced 34 figures using
Python 3.14.2 and NumPy 2.4.1. Validation executes cells sequentially in a fresh
Python process and captures Matplotlib output; it is not a separate interactive
Jupyter-browser rendering test. release_audit.json records the additional
relocated-folder execution after path cleanup.
The appended Section 17 passed a separate fresh-kernel run of all four new
code cells and four figures; thermal_angular_execution_report.json records the
updated notebook checksum. The preceding 81 cells were verified unchanged.
Section 18 adds two independently executed cached plotting cells and two figures;
hot_spectra_execution_report.json contains the current notebook checksum.

public_manifest.json covers data files, not the entire distribution. The
notebook hash is in execution_report.json. Hashes inside provenance records
may describe unbundled original inputs; they do not imply those inputs are
present. source_mapping.json describes earlier extraction history only.

7. Scientific scope and limitations
==================================
Projected D/P channels are not exact full-operator branches. Section 12.4
checks four P0 avoided crossings in the full even-parity operator. We minimize
the absolute gap and quote full splitting divided by the pair mean. The
largest among these four is 1.1757%, about 1.2%; this is not a proven global
bound over infinitely many encounters. Opposite-parity modes do not mix.

The k^6 polarization coefficient is not yet fully converged. Its shaded range
measures extrapolation sensitivity, not statistical confidence. All plotted
finite-thickness reconstructions keep the leading k approximation above.
We do not claim uniform sixth-order accuracy, particularly at tau = 2.
Polarization residuals are fractions, not percentages, even when the left-hand
polarization curves are shown in percent.

compPSc iteration convergence is distinct from full mesh convergence. The
benchmarks do not prove agreement in every bin. We use diagonal MCRT errors,
omitting inter-bin covariance and deterministic model numerical error.
Large chi2/N may reflect small statistical errors; it is not a fractional
spectral error or a simulation-size-independent distance. No formal p-values
are assigned.

8. Path redaction and provenance
===============================
Production manifests retain physical settings, seeds, photon budgets, timings,
return codes and executable hashes. Machine-specific absolute paths in recorded
commands are replaced by logical identifiers such as external-production/low/.
These identify historical production files only. The referenced executable,
opacity tables, seed-CDF files and raw output directories are NOT bundled
paths and are NOT executed by this notebook. Numerical values were unchanged.
